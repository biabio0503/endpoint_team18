# 스텝업 프론트엔드

기존 스텝업 UI 시안을 React와 Vite 컴포넌트로 구현한 프로젝트입니다.

## 실행 방법

Node.js 18 이상이 설치된 터미널에서:

```bash
npm install
npm run dev
```

터미널에 나타난 주소를 브라우저에서 엽니다. 배포용 빌드는 `npm run build`로 생성합니다.

## 현재 기능

- 시작, 대시보드, 기본 정보, 경험·문서, 이수 과목, 역량 탐색, 로드맵 화면
- 필수 목표 입력 검사와 테두리 애니메이션, 메뉴 이동
- 기본 정보와 선택 과목, 역할 답변의 브라우저 저장
- 문서 선택·삭제 및 예시 문서 역할 확인 (파일 자체는 저장하거나 서버에 전송하지 않음)
- 예시 역량 검색과 상세 정보, 예시 로드맵 탭

## 연동 전인 기능

Google 로그인, 실제 문서 업로드 및 분석, 학교별 교육과정, AI 분석, 직무·공고 추천, 서버 저장은 구현되어 있지 않습니다. 현재 표시되는 역량 및 로드맵은 예시입니다. 브라우저 저장소를 삭제하거나 다른 기기/브라우저로 바꾸면 입력값이 유지되지 않습니다.
