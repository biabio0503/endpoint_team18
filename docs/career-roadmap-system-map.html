구현 규모

단일 웹 프런트엔드, 하나의 백엔드, 관계형 DB와 비공개 파일 저장소를 기본 단위로 봅니다. 문서 처리와 출처별 정기 수집은 DB 상태를 처리하는 워커로 연결합니다.

직무 요구의 의미 해석, 사용자 역량 판정, 추천 순서·이유 생성은 AI 담당 모듈의 계약으로 남깁니다. 비AI 서버는 수집·검증·참조 연결·저장·표시를 구현합니다.

스택·호스팅 제품은 아직 확정하지 않았습니다. 그림의 박스는 논리 모듈입니다.

구현 전에 수치·정책만 확정할 항목

  • 업로드 파일 개수·용량·파싱 제한
  • 보호된 세션 유효기간과 문서·결과 보관 기간
  • 외부 분석 모듈의 입력·출력 계약, 오류·시간 제한
  • 최초 지원 학과·과목 목록 버전과 출처
  • 문서 삭제 시 파생 자료와 과거 결과의 정리 정책
  • 수집 출처·허용 경로·수집 주기·재시도·정보 유효기간
  • 원문 구절 보관 범위와 모집 기한·시간대 처리
목업에 새로운 설정 화면을 추가하지 않고 서버 설정으로 관리합니다.
